This module contains code to create audio to conduct target detection via audio modality.
The goal is to take a base audio from an urban or non urban environment and overlay soundeffects such as Gunshots, Explosions, UAV, Anomals, Humans, etc.
These new audio will allow us to first study sound classification and detection. Ultimately after accurately detecting and classifying soundeffects, the goal
is to attempt to extract additional infromation such as speed of travel and proximity. 

Module: create_syn_audio.py
- This file contains a class to create the audio file and store all metadata related to the overlayed audios.
