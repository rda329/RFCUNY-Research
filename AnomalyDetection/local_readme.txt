This directory attempts to perform audio classification using unsupervised learning methods.
The problem was approached through the lens of anomaly detection.

Data:
The code for pre-processing the audio data in preperation for modeling can be found in Data_n_Features_code.
The notebook data_notebook.ipynb executes code to overlay a "base audio" with a class of interest "anomaly".

The resulting audios and a jsons containing meta-data for the audios can be found in ./Data_v1.
The audio meta-data is contained in a table of content "toc.json".
