This module contains code used to conduct anomaly detection on the audio files. 

Module: DataManipulate.py
- This file contains a class that handles test train splits, and data preprocessing 

Module: detection_methods.py
- This file contains a class that implements different anomaly detection detection_methods
    PCA detection_methods
    Isolation Forest Method
