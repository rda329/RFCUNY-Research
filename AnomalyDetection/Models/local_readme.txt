# Anomaly Detection Module

This directory contains anomaly detection pipelines for identifying anomalous audio segments after preprocessing.

## Files

### `AnomalyDetection.py`

Implements unsupervised anomaly detection methods using the feature vectors generated by `DataManipulate.py`.

**Implemented Methods**

* **Principal Component Analysis (PCA)**

  * Projects audio features into a lower-dimensional space while preserving a target percentage of variance.
  * Uses reconstruction error as the anomaly score.
  * Produces mean ROC and Precision-Recall curves across all processed audio files.

* **Isolation Forest**

  * Trains an Isolation Forest model on FFT feature vectors.
  * Evaluates performance using:

    * Precision
    * Recall
    * Confusion Matrix (TN, FP, FN, TP)
    * ROC-AUC
    * PR-AUC
  * Returns a Pandas DataFrame containing evaluation metrics for each processed audio file.
  * Generates mean ROC and Precision-Recall curves across the dataset.

## Dependencies

This module depends on:

* `DataManipulate.py` for loading and preprocessing audio data.
* `scikit-learn` for PCA and evaluation metrics.
* `PyOD` for the Isolation Forest implementation.
* `matplotlib` for visualization.

## Workflow

```text
Synthetic Audio (.wav + .json)
            │
            ▼
     DataManipulate.py
            │

 FFT Feature DataFrame
            │
            ▼
 AnomalyDetection.py
      ├── PCA
      └── Isolation Forest
            │
            ▼
Evaluation Metrics & ROC / PR Curves
```
